# 연애심리 대본 생성 가이드

## 목적

연애심리 콘텐츠는 시청자가 자기 상황에 바로 대입할 수 있어야 한다. 자극적인 단정, 출처 없는 통계, 특정 유형 낙인보다 "관계 패턴을 이해하고 다음 행동을 점검하게 만드는 대본"을 우선한다.

## 생성 전 필수 절차

대본을 바로 쓰지 말고 아래 순서로 작업한다.

```text
1. 주제 확정
2. 핵심 주장 1개로 압축
3. 팩트 확인
4. 쇼츠 또는 롱폼 규격 선택
5. 대본 작성
6. 자체 검수
```

## 팩트 확인 규칙

- 웹 검색이 가능한 생성형 AI라면 대본 작성 전에 검색을 먼저 한다.
- 검색 우선순위는 학술 논문, 대학/학회 자료, 공신력 있는 심리학 서적 정보, 병원/전문가 감수 자료, 일반 매체 순서다.
- 블로그, 커뮤니티, 짧은 카드뉴스만 근거로 연구자, 연도, 통계를 말하지 않는다.
- 최소 2개 이상의 출처에서 같은 방향으로 확인되는 내용만 강한 표현으로 쓴다.
- 심리학 개념, 연구자, 연도, 통계, 대학명, 논문명은 반드시 확인된 경우에만 쓴다.
- 확인하지 못한 수치, 특정 대학 연구, 연도, 논문명은 만들지 않는다.
- 확실하지 않은 내용은 "연구에 따르면"이라고 쓰지 말고 "애착 이론에서는", "상담 장면에서는", "관계에서 자주 보이는 패턴은"처럼 낮은 확신 표현을 쓴다.
- 통계는 출처가 명확할 때만 사용한다. 출처가 없으면 "많은 사람", "일부 연구", "상당수" 같은 애매한 수량 표현도 남발하지 않는다.
- 대본 안에 사실 주장이 들어가면, 마지막에 내부 검수용으로 `팩트 체크 메모`를 따로 작성한다.
- 시청자에게 보여주는 최종 대본에는 출처 나열을 넣지 않는다. 단, 제작자가 원하면 설명란용 출처를 별도로 제공한다.

## 우선 참고할 수 있는 검증 기준

애착유형 콘텐츠를 만들 때는 아래 수준의 안정적인 기준만 사용한다.

```text
Bowlby: 애착이론의 기초를 세운 연구자. Attachment and Loss 1권은 1969년에 출간.
Ainsworth: 낯선 상황 절차를 통해 유아 애착 패턴 연구를 확장.
Hazan & Shaver: 1987년 성인 연애 관계를 애착 과정으로 설명.
Bartholomew & Horowitz: 1991년 성인 애착을 자기 모델과 타인 모델을 바탕으로 4범주로 설명.
```

표현할 때는 이렇게 쓴다.

```text
좋음: 성인 애착 연구에서는 안정형, 불안형, 회피형, 두려움-회피형처럼 관계 속 불안과 회피 수준에 따라 설명하기도 합니다.
나쁨: 성인 애착은 무조건 안정형, 불안형, 회피형, 혼란형 4가지로 딱 나뉩니다.
```

## 출력 형식 선택

사용자가 형식을 지정하지 않으면 먼저 쇼츠용으로 작성한다. 사용자가 롱폼, 유튜브 긴 영상, 5분 이상, 설명형 콘텐츠를 원하면 롱폼 규격을 사용한다.

## 쇼츠 대본 규격

목표 길이: 35~60초

권장 분량:

```text
훅: 1~2문장
본론: 6~8문장
결론: 1~2문장
전체: 8~12문장
```

구성:

```text
훅
[시청자가 자기 상황을 떠올릴 질문 또는 반전 1개]

본론
[개념 정의 1문장]
[핵심 유형/패턴 설명 3~5문장]
[오해 바로잡기 1문장]
[결론으로 이어지는 전환 1문장]

결론
[시청자가 오늘 바로 점검할 행동 1개]
```

쇼츠 작성 규칙:

- 한 문장은 짧게 쓴다. 한 문장에 정보 2개 이상을 넣지 않는다.
- 유형을 다룰 때는 모든 유형을 길게 설명하려 하지 말고, 주제와 직접 관련된 차이만 뽑는다.
- 그래도 애착유형 4가지를 제목에서 언급했다면 안정형, 불안형, 회피형, 두려움-회피형을 모두 최소 1번씩 설명한다.
- 마지막 문장은 댓글 유도보다 행동 제안이 우선이다.
- 결론은 "검사해 보세요"로 끝내지 않는다. 관찰 포인트나 대화 행동을 제시한다.

## 롱폼 대본 규격

목표 길이: 5~8분

권장 분량:

```text
오프닝 훅: 3~5문장
문제 제기: 5~7문장
개념 설명: 8~12문장
유형별 설명: 유형당 4~6문장
사례: 1~2개, 사례당 5~8문장
오해 바로잡기: 5~8문장
실천법: 3~5개, 각 2~4문장
결론: 4~6문장
```

구성:

```text
오프닝
[시청자 상황 공감]
[오늘 영상에서 풀 질문]

문제 제기
[왜 이 주제가 연애에서 반복되는지]

핵심 개념
[용어 정의]
[검증된 배경 설명]
[과장하면 안 되는 지점]

본론 1
[유형/패턴별 설명]

본론 2
[현실 사례]
[상대 탓으로 단정하지 않는 해석]

본론 3
[오해 바로잡기]
[실천법]

결론
[핵심 요약]
[오늘 적용할 행동]
[다음 콘텐츠로 이어지는 질문]
```

롱폼 작성 규칙:

- 정보량을 늘리되 문단마다 역할이 달라야 한다. 같은 말을 반복해서 길게 만들지 않는다.
- 각 60~90초마다 예시, 질문, 반전, 체크리스트 중 하나를 넣어 이탈을 줄인다.
- 연구자와 이론 설명은 20~30초 안에 끝내고, 바로 연애 상황 예시로 연결한다.
- 사례는 특정 성별을 악역으로 만들지 않는다.
- 실천법은 "자존감을 높이세요" 같은 추상어로 끝내지 말고 말문 예시를 준다.

예:

```text
"너 왜 답장 안 해?" 대신 "답이 늦어지면 내가 버려진 것처럼 느껴질 때가 있어. 바쁠 때는 나중에 답한다고 한마디만 해줄 수 있어?"처럼 요청으로 바꿔 말합니다.
```

## 쇼츠 기본 출력 구조

쇼츠는 아래 3단 구조를 유지한다. 롱폼은 앞의 롱폼 규격을 따른다.

```text
훅
[1~2문장]

본론
[6~9문장]

결론
[1~2문장]
```

## 훅 작성 규칙

- 첫 문장은 시청자가 바로 자기 상황을 떠올리게 쓴다.
- "무조건", "평생", "결정짓습니다"처럼 과도한 단정은 피한다.
- 주제가 애착유형이면 4가지 유형 이름을 나열하는 것보다, "왜 내 연애가 반복되는지"를 먼저 건드린다.
- 쇼츠에서는 3초 안에 갈등 상황이 보여야 한다.
- 롱폼에서는 공감, 질문, 약속을 모두 넣는다.

좋은 예:

```text
훅
연애할 때 자꾸 불안해지거나, 반대로 가까워질수록 도망가고 싶다면 애착유형을 봐야 합니다.
```

피해야 할 예:

```text
훅
성인 애착유형 4가지, 첫 연애를 좌우합니다.
```

## 본론 작성 규칙

- 핵심 개념을 먼저 정의한 뒤, 유형별 차이를 균형 있게 설명한다.
- 여러 유형을 다룰 때는 특정 유형 하나가 빠지면 안 된다.
- 안정형은 "문제가 없는 사람"이 아니라 "불안과 갈등을 비교적 조절하고 회복하는 패턴"으로 설명한다.
- 불안형은 "확인을 많이 요구하는 사람"으로만 쓰지 말고, 버려질지 모른다는 민감성과 안심 욕구를 함께 설명한다.
- 회피형은 "차갑다"로 낙인찍지 말고, 친밀감이 커질 때 부담을 느끼고 거리를 두는 방어 패턴으로 설명한다.
- 두려움-회피형 또는 혼란형은 불안형과 회피형이 섞인 패턴으로, 가까워지고 싶지만 동시에 두려워하는 양가성을 설명한다.
- 모태솔로, 첫 연애, 부모 관계를 다룰 때는 단정하지 않는다. "반드시 투영된다"가 아니라 "드러날 가능성이 있다"로 쓴다.
- 통계, 대학 연구, 연도, 논문명을 언급하려면 실제 확인된 근거가 있을 때만 쓴다. 확인되지 않았다면 "일부 연구에서는", "애착 이론에서는"처럼 일반 표현을 쓴다.
- 퍼센트 수치를 쓸 때는 합계가 이상하지 않게 확인한다. 확실하지 않으면 수치를 빼고 비중 표현으로 바꾼다.
- 결론으로 이어질 문장을 본론 마지막에 따로 둔다. "그래서 무엇을 해야 하는가"가 자연스럽게 보여야 한다.
- 본론이 부실해지지 않도록 반드시 `정의 -> 현실 신호 -> 오해 -> 적용` 순서를 포함한다.
- 단순 정보 나열이 아니라 "그래서 연애에서 어떻게 나타나는지"를 매 문단마다 연결한다.

## 결론 작성 규칙

- 결론은 공포나 단정이 아니라 점검과 행동 제안으로 끝낸다.
- "첫 상대가 이후 연애를 결정한다"처럼 운명론으로 끝내지 않는다.
- 좋은 결론은 다음 중 하나를 포함한다.
  - 내 반응 패턴 관찰
  - 상대 탓만 하기 전 내 불안/회피 방식 점검
  - 안정형처럼 회복하는 연습
  - 대화, 거리 조절, 감정 표현 같은 구체 행동
- 결론은 본론에서 나온 핵심 주장과 직접 연결되어야 한다. 갑자기 "검사해 보세요", "상담받으세요"로 끝내지 않는다.
- 쇼츠 결론은 행동 1개, 롱폼 결론은 요약 2문장과 행동 1~2개를 포함한다.

좋은 예:

```text
결론
중요한 건 어떤 유형인지 맞히는 게 아니라, 갈등이 생겼을 때 내가 불안으로 매달리는지 회피로 닫히는지 알아차리는 겁니다.
안정형에 가까워지는 연애는 타고나는 것이 아니라, 감정을 말하고 회복하는 방식을 반복해서 배우는 데서 시작됩니다.
```

피해야 할 예:

```text
결론
지금 나의 애착유형부터 정확하게 점검해 보시기 바랍니다.
```

## 애착유형 주제 필수 포함 요소

애착유형을 주제로 대본을 만들 때는 아래 4가지를 모두 포함한다.

```text
안정형: 가까워져도 자신을 잃지 않고, 갈등 후 대화와 회복을 시도하는 유형
불안형: 상대 반응에 민감하고, 확인과 안심을 자주 필요로 하는 유형
회피형: 친밀감이 커질수록 부담을 느끼고, 혼자만의 거리로 안정감을 찾는 유형
두려움-회피형 또는 혼란형: 가까워지고 싶지만 상처받을까 봐 동시에 밀어내는 유형
```

안정형 설명은 반드시 1문장 이상 넣는다. 안정형을 단순히 "정상", "좋은 유형", "문제 없음"으로 쓰지 않는다.

성인 애착 대본에서는 "혼란형"이라고만 단정하지 말고, 가능하면 "두려움-회피형 또는 혼란형"처럼 용어 차이를 부드럽게 처리한다.

## 내용 밀도 체크리스트

대본 제출 전 아래 항목을 자체 점검한다.

```text
[ ] 첫 3초에 볼 이유가 있는가?
[ ] 핵심 주장이 1개로 선명한가?
[ ] 안정형 설명이 빠지지 않았는가?
[ ] 연구자, 연도, 통계가 검증 없이 들어가지 않았는가?
[ ] 본론에 현실 예시가 1개 이상 있는가?
[ ] 결론이 본론과 연결되는가?
[ ] 시청자가 오늘 적용할 행동이 있는가?
[ ] 특정 유형이나 성별을 비난하지 않는가?
```

## 생성 AI에게 줄 최종 지시문 템플릿

아래 템플릿을 그대로 사용한다.

```text
너는 연애심리 유튜브 대본 작가다.
주제: [주제 입력]
형식: [쇼츠/롱폼]
대상: [예: 20~30대 연애 고민 시청자]

작성 전 먼저 웹 검색 또는 제공된 자료 검색으로 팩트를 점검하라.
검색이 불가능한 환경이면 검증되지 않은 연구자, 연도, 통계는 쓰지 말고 일반 개념으로만 설명하라.
확인되지 않은 연구자, 대학명, 연도, 퍼센트 통계는 절대 만들지 마라.
심리학 개념은 단정하지 말고, 관계에서 나타나는 경향으로 설명하라.

대본은 아래 구조로 작성하라.
쇼츠면 훅 1~2문장, 본론 6~8문장, 결론 1~2문장으로 쓴다.
롱폼이면 오프닝, 문제 제기, 핵심 개념, 유형/패턴 설명, 사례, 오해 바로잡기, 실천법, 결론 순서로 쓴다.

내용은 부실하게 요약하지 말고 반드시 정의, 현실 신호, 오해, 적용을 포함하라.
애착유형을 다루면 안정형, 불안형, 회피형, 두려움-회피형 또는 혼란형을 균형 있게 설명하라.
안정형은 반드시 갈등 후 대화와 회복을 시도하는 패턴으로 설명하라.

결론은 "검사해 보세요"로 끝내지 말고, 시청자가 오늘 적용할 행동을 제시하라.
```

## 예시 대본

### 쇼츠 예시

```text
훅
연애할 때 자꾸 불안해지거나, 가까워질수록 오히려 도망가고 싶다면 애착유형을 봐야 합니다.

본론
애착유형은 사람이 친밀한 관계에서 안정감을 얻고 불안을 다루는 방식을 설명하는 개념입니다.
성인 애착은 보통 안정형, 불안형, 회피형, 두려움-회피형 또는 혼란형으로 나눠 설명합니다.
안정형은 상대와 가까워져도 자신을 잃지 않고, 갈등이 생겼을 때 대화와 회복을 시도합니다.
불안형은 상대의 답장, 표정, 말투 변화에 민감하고 사랑이 식은 것은 아닌지 자주 확인하고 싶어집니다.
회피형은 친밀감이 깊어질수록 부담을 느끼고, 혼자만의 시간이나 거리 두기로 안정감을 찾습니다.
두려움-회피형은 가까워지고 싶은 마음과 상처받을까 봐 밀어내는 마음이 함께 나타날 수 있습니다.
첫 연애에서는 이런 패턴이 더 낯설게 드러날 수 있습니다.
경험이 적을수록 내 불안이 사랑인지, 경계심인지, 회피인지 구분하기 어렵기 때문입니다.
그래서 중요한 건 상대를 유형으로 단정하는 것이 아니라, 갈등이 생겼을 때 내가 어떤 방식으로 반응하는지 보는 것입니다.

결론
애착유형은 사람을 분류하는 딱지가 아니라, 관계에서 반복되는 반응을 알아차리는 지도에 가깝습니다.
안정형에 가까워지는 연애는 감정을 숨기거나 매달리는 대신, 말하고 조절하고 다시 회복하는 연습에서 시작됩니다.
```

### 롱폼 도입 예시

```text
오프닝
답장이 조금만 늦어져도 마음이 무너지는 사람이 있습니다.
반대로 관계가 진지해질수록 갑자기 혼자 있고 싶어지는 사람도 있습니다.
둘 중 누가 더 나쁘다는 이야기가 아닙니다.
오늘은 애착유형이 연애에서 어떻게 나타나는지, 그리고 안정형에 가까워지려면 무엇을 연습해야 하는지 이야기하겠습니다.

문제 제기
많은 사람이 애착유형을 성격 테스트처럼 사용합니다.
"나는 불안형이니까 어쩔 수 없어", "저 사람은 회피형이라 답이 없어"라고 결론을 내립니다.
하지만 애착유형은 사람을 낙인찍는 이름표가 아닙니다.
가까운 관계에서 불안과 친밀감을 어떻게 다루는지 보여주는 패턴에 가깝습니다.
그래서 중요한 질문은 "나는 무슨 유형인가"에서 끝나면 안 됩니다.
"갈등이 생겼을 때 나는 매달리는가, 닫히는가, 아니면 말하고 회복하려 하는가"까지 봐야 합니다.
```
